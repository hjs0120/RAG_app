## 시나리오 1: 검색 결과가 충분한 질문

**목적**: 관련 chunk가 충분히 검색되어 답변이 정상 생성되는지 확인

**질문 예시**

- "제10조 검사 주기는 얼마인가?"
- "정기검사 실시 조건은?"
- "안전장치 요구사항을 설명해 주세요"

**확인 사항**

- [x] 검색 결과 Top-k에 관련 chunk가 상위에 포함됨
- [x] 답변이 문서 내용에 기반하여 작성됨
- [x] 답변 말미에 `[출처]` 섹션이 있음
- [x] 출처 형식이 `[1] doc_id=..., page=..., section=...` 형태임

---

## 시나리오 2: 검색 결과가 부족한 질문

**목적**: 문서에 없는 내용에 대해 "관련 근거를 찾지 못했습니다" 또는 적절한 거절 메시지가 나오는지 확인

**질문 예시**

- "우주선 발사 절차는?"
- "해당 규칙에 없는 완전히 무관한 주제"
- "제999조는 무엇인가?" (존재하지 않는 조항)

**확인 사항**

- [x] 검색 결과가 없거나 점수가 낮음
- [x] 답변이 "관련 근거를 찾지 못했습니다" 또는 유사한 메시지로 처리됨
- [x] LLM이 문서 외 정보를 임의로 만들어내지 않음

---

## 시나리오 3: section이 섞여 들어오는 질문

**목적**: 동일 조문(article) 내 여러 절(section)이 검색될 때 재조합 및 답변 품질 확인

**질문 예시**

- "제101조 내용 전체를 요약해 주세요" (101. 적용, 101. 일반, 101. 하중 등 여러 절 포함)
- "검사 관련 조항을 모두 정리해 주세요"

**확인 사항**

- [x] 검색 결과에 여러 section이 포함됨 (예: 101.적용, 101.하중)
- [x] chunk_assembler가 article+section 단위로 그룹핑함
- [x] 답변이 여러 절을 종합하여 작성됨
- [x] 출처에 여러 section이 올바르게 나열됨

---

## 시나리오 4: 출처가 제대로 붙는지 확인

**목적**: 답변의 인용/근거가 출처 번호와 대응하는지 확인

**질문 예시**

- "제10조 검사 주기는 얼마인가?" (구체적 수치가 있는 조항)

**확인 사항**

- [x] 답변에서 인용한 내용에 `[1]`, `[2]` 등 출처 번호가 붙어 있음
- [x] 출처 목록과 답변 내 번호가 일치함
- [x] `[출처]` 섹션에 제공된 출처 형식이 그대로 유지됨 (임의 변경 없음)

---

## 시나리오 5: Ollama가 꺼져 있을 때 오류 처리 확인

**목적**: Ollama 미실행 시 사용자에게 명확한 안내 메시지가 표시되는지 확인

**절차**

1. Ollama를 종료 (시스템 트레이에서 종료 또는 `ollama` 프로세스 종료)
2. RAG 탭에서 질문 입력 후 [답변 생성] 클릭
3. 오류 메시지 확인

**확인 사항**

- [x] "Ollama가 실행되지 않았습니다" 또는 유사한 안내 메시지가 표시됨
- [x] 앱이 크래시하지 않음
- [x] [검색] 버튼은 Ollama 없이도 동작함 (검색만 수행)
- [x] Ollama 재실행 후 [답변 생성]이 정상 동작함
